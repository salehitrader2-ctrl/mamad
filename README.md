# راندمان — فاز اول (ماژول اداری)

پلتفرم مدیریت منابع انسانی و بهره‌وری برای شرکت‌های تولیدی، به‌صورت PWA
(نصب‌شدنی روی موبایل و قابل‌استفاده روی ویندوز از همان مرورگر).

این فاز اول («wedge») روی حذف بروکراسی کاغذی تمرکز دارد: درخواست مرخصی و
مانده‌ی آن، درخواست وام، و درخواست فیش حقوقی — همراه با گردش تأیید برای
سرپرست/منابع انسانی. ماژول‌های هدف‌گذاری، برنامه‌ریزی و آموزش/امتیازدهی
(طبق نقشه‌راه توافق‌شده) در فازهای بعدی روی همین پایه (کاربران، شرکت،
نقش‌ها) اضافه می‌شوند.

## ساختار پروژه

```
backend/    API با Express + Prisma (SQLite در حالت توسعه)
frontend/   اپ React + Vite به‌صورت PWA (RTL، فارسی، طراحی مینیمال)
```

## اجرای محلی

### بک‌اند

```bash
cd backend
cp .env.example .env
npm install
npx prisma migrate dev --name init
npm run db:seed
npm run dev        # http://localhost:4000
```

حساب‌های نمونه (رمز همه: `Passw0rd!`):

| نقش              | کد ملی       |
| ---------------- | ------------ |
| منابع انسانی      | 0011111111   |
| سرپرست            | 0022222222   |
| کارمند            | 0033333333   |
| کارمند            | 0044444444   |

### فرانت‌اند

```bash
cd frontend
npm install
npm run dev         # http://localhost:5173  (درخواست‌های /api از طریق پروکسی به 4000 می‌روند)
```

برای build نهایی (شامل service worker و manifest):

```bash
npm run build
npm run preview
```

## معماری و تصمیم‌های طراحی

- **نقش‌ها**: `EMPLOYEE` (فقط دیدن/ثبت درخواست‌های خودش)، `MANAGER` (تأیید
  درخواست‌های زیرمجموعه‌ی مستقیم)، `HR_ADMIN` (تأیید همه‌ی درخواست‌های شرکت).
- **تأیید مرخصی** به‌صورت خودکار از مانده‌ی مرخصی کاربر کسر می‌شود (در یک
  تراکنش دیتابیسی، تا از ناهماهنگی جلوگیری شود).
- **PWA**: قابل نصب روی صفحه‌ی اصلی موبایل بدون نیاز به فروشگاه اپ (مهم
  برای بازار ایران به‌خاطر محدودیت انتشار در Google Play/App Store)؛ با
  `vite-plugin-pwa` و فونت وزیرمتن به‌صورت self-host (کار آفلاین بعد از
  نصب).
- **طراحی**: پالت کم‌اشباع و آرام (بدون رنگ جیغ)، عمداً برای حس «ابزار کاری
  جدی» نه اپ سرگرمی. چیدمان موبایل با نوار پایین (bottom tab bar)، چیدمان
  دسکتاپ با سایدبار — از همان کدبیس، بدون اپ جدا.
- **تاریخ**: نمایش تاریخ‌ها با تقویم جلالی (`Intl` با `fa-IR-u-ca-persian`).

## نقشه‌راه بعدی (طبق بحث استراتژی)

1. ماژول هدف‌گذاری و برنامه‌ریزی (کوتاه/بلندمدت) برای سرپرست‌ها.
2. ماژول آموزش + امتیازدهی (کتاب/مقاله/ویدیو) متصل به جایگاه شغلی هر فرد.
3. یکپارچه‌سازی با نرم‌افزارهای حسابداری/ERP رایج (بعد از گرفتن چند
   نمونه‌کار موفق).
